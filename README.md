# Aaron-YOUTUBE

Personal landing page + **World Warrior Turbo**, an original arcade-style fighting game.

## 🎮 World Warrior Turbo

A handheld, mobile-first 1-on-1 fighting game inspired by classic arcade brawlers
(think *Street Fighter II Turbo* feel). It runs entirely in the browser — no app
store, no install needed — and can be added to your phone's home screen to play
like a real handheld, even offline.

**File:** [`fighter.html`](fighter.html)

### Features
- 4 original fighters, each with their own colors, speed and power
- **Arcade mode** (fight a ladder of CPU opponents) and **2-player Versus**
- Best-of-3 rounds, health bars, round timer, K.O. system
- Special moves: **Fireball**, **Rising Uppercut**, **Spin Kick**
- Light/heavy punches & kicks, crouching, jumping, blocking
- On-screen touch controls for phones + keyboard support for desktop
- Procedural sound effects (Web Audio) — no audio files
- Installable PWA with offline support (service worker)

### How to play (touch)
- **◀ ▶** move · **JUMP** / **DUCK**
- **LP / HP** light / heavy punch · **LK / HK** light / heavy kick
- **BLOCK** (or hold away from your opponent) to guard
- **Fireball:** hold toward opponent + **HP**
- **Uppercut:** hold away + **HP**
- **Spin Kick:** hold **DUCK** + **HK**

### How to play (keyboard, for desktop testing)
- **P1:** A/D move, W jump, S duck, F/G punch, V/B kick, Left-Shift block
- **P2:** ←/→ move, ↑ jump, ↓ duck, K/L punch, N/M kick, Enter block

### Put it on your Samsung phone (handheld mode)
1. Host these files (e.g. GitHub Pages) or open `fighter.html` directly.
2. Open the page in Chrome on your phone.
3. Tap the **⋮** menu → **Add to Home screen**.
4. Launch from the new icon — it opens fullscreen in landscape like a real handheld.

> ⚠️ **Note:** This is a 100% original game. It does **not** contain any Capcom /
> Street Fighter sprites, audio, characters, or ROM data — all artwork is drawn
> with code. That keeps it legal to share and publish.
